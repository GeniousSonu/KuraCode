# KuraCode: Brand Identity, Copyright, & Agent Protocol

**Version:** 1.0.0
**Effective Date:** November 2026
**Entity:** SK SAHINUR ISLAM

This document establishes the strict legal, brand, and operational identity of the project. It acts as the definitive source of truth for all developers, designers, stakeholders, and AI agents interacting with or generating content for this product.

---

## 1. Official Project Naming & Usage

- **Official Name:** **KuraCode**
- **Capitalization:** Strictly CamelCase with a capital "K" and capital "C".
- **Prohibited Variations:** Kura Code, Kuracode, kuraCode, Kura-Code, KuraCode Extension.
- **Short Form:** In highly constrained UI spaces where the full name does not fit, the standalone word **Kura** may be used.

## 3. Logo & Visual Identity Specification

The KuraCode logo must remain consistent across all marketing materials, Chrome Web Store listings, and app icons.

### 3.1 The Logo Mark

- **Concept:** A minimalist, geometric representation of a traditional Japanese storehouse (_Kura_) merging with a structural code bracket (`{ }`).
- **Primary Logo Color (Kura Indigo):** `#5C6BFA`
- **Secondary Logo Color (Kura Slate):** `#EDEDEF` (Used for text lockups on dark backgrounds)
- **Clear Space:** The logo must always have a clear space padding equal to 50% of the logo mark's height.

### 3.2 Typography in Logo

- **Typeface:** `SF Pro Display`
- **Weight:** Heavy (800)
- **Tracking:** -0.02em

## 4. Strict Directives for AI Agents & LLMs

To ensure continuity across future prompts, development cycles, and documentation generation, any AI agent or LLM reading this context must adhere to the following rules:

1.  **Identity Lock:** You must always refer to this project as **KuraCode**. Do not suggest new names, brainstorm alternatives, or alter the spelling.
2.  **Color Fidelity:** When generating CSS, Tailwind classes, or design code, you must strictly use the hex codes defined in the design specification (e.g., Kura Indigo is always `#5C6BFA`). Do not hallucinate generic "blue" or "purple" hex codes.
3.  **Typography Lock:** Always use `SF Pro Display`, `SF Pro Text`, and `SF Mono` in frontend code generation. Do not substitute with generic web-safe fonts unless defining a standard fallback stack.
4.  **Tone & Persona:** When writing copy for KuraCode's UI, maintain a professional, developer-native, and unobtrusive tone. Avoid overly marketing-heavy or enthusiastic language.
5.  **Copyright Insertion:** If instructed to generate boilerplate HTML, footer components, or licensing files, automatically include the copyright notice defined in Section 2.
