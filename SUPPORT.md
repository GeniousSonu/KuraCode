# Support for KuraCode (SnipHub)

Thank you for using KuraCode! If you encounter issues, have questions, or would like to request features, here is how to get help:

---

## 1. Documentation & Guides
Before opening an issue, check the documentation:
- [README.md](README.md): Quick start, installation, feature highlights.
- [docs/PRD.md](docs/PRD.md): Product architecture and functional design.
- [docs/PUBLISHING.md](docs/PUBLISHING.md): Store guidelines, releases, and distribution details.

---

## 2. Reporting Issues
- **Bug Reports:** If something is broken on a specific website, open a [Bug Report](https://github.com/kuracode/kuracode/issues/new?template=bug_report.yml) detailing your browser, OS, and URL.
- **Site Adapter Failures:** If a code block on a website fails to clean or capture properly, submit a [Site Adapter Report](https://github.com/kuracode/kuracode/issues/new?template=site_adapter.yml).
- **Feature Requests:** Suggest improvements via [Feature Request](https://github.com/kuracode/kuracode/issues/new?template=feature_request.yml).

---

## 3. Security Concerns
Please refer to [SECURITY.md](SECURITY.md) to report vulnerabilities privately.
