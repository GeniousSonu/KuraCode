## Detailed Description
```markdown
Capture code from any web page in one click with its context intact.

KuraCode is the developer-native snippet capture extension. When browsing documentation, StackOverflow, or GitHub, save clean, runnable code with its full origin context intact.

FEATURES:
• One-click hover capture button on code blocks
• Global shortcut: Ctrl+Shift+S (Command+Shift+S on Mac)
• Smart cleaning: strips line numbers, prompt signs ($ and >), trailing spaces
• Context memory: saves source URL, page title, and nearby heading
• Instant search by tag, language, or content
• 100% local-first and private storage
```

## Notes for Certification Testers
```markdown
Testing Instructions for Microsoft Edge Certification Team:

1. Install the extension.
2. Navigate to any web page containing a <pre> code block (e.g., https://developer.mozilla.org/ or https://github.com/).
3. Hover over any code block: notice the subtle "Save" button in the upper right. Click "Save".
4. Alternatively, highlight any text and press Ctrl+Shift+S (or right-click and choose "Save selection to KuraCode").
5. Click the KuraCode extension icon in the browser toolbar:
   - Notice the saved code snippet rendered with source URL and language tags.
   - Test instant search by typing a keyword into the search bar.
   - Click the copy button to copy clean code to clipboard.
6. The extension is completely self-contained and operates offline without remote servers.
```
