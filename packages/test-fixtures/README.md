# Test Fixtures

Saved, anonymized HTML pages of real code sites, for capture/cleaner/language-detection tests. Each fixture is a `.html` file (stripped of personal data) representing a real page shape.

Planned sources (≥15): Stack Overflow, GitHub blob, GitHub gist, GitHub PR diff, README, MDN, dev.to, Medium, Reddit, StackBlitz, CodeSandbox, docs frameworks (Docusaurus/Nextra), ChatGPT-style chat code blocks, Jupyter-rendered pages.

## Current
- `simple.html` — minimal `<pre><code>` page (used by the extension e2e smoke test).
