script (`npm run brand:build`) and committed; never hand-edit generated files.

| Token | Hex | Use |

| Kura Graphite | `#0C0D10` | social/OG background (UI neutral) |

Logo is green/mint. **UI accent tokens are separate** (warm gold) and do not
modify the logo. See `docs/DESIGN.md` and `docs/agent/DECISIONS.md`.

## 4. Usage rules

- **Do** use the master SVG for any resolution; rasterize at target size (never upscale a small PNG).
- **Do** keep the mark clear of edges: minimum clear space ≈ 10% of the icon canvas.
- **Don't** redraw, recolor, restyle, or add effects to the logo.
- **Don't** place the logo on busy backgrounds; the mark needs contrast.
- Light toolbar = `action/icon-light-*`, dark toolbar = `action/icon-dark-*` (switch via `chrome.action.setIcon` on `prefers-color-scheme`).
- Small sizes use the mark only (no wordmark exists yet — see IMPROVEMENTS).

## 5. Regeneration

```sh
npm run brand:build   # deterministic, writes brand/generated/
npm run brand:check   # dimension + SVG + manifest/build-reference assertions
npm run build         # runs brand:build first
```

Generated files are **committed** (so a fresh checkout works without Node tooling)
and also re-generated in CI before `brand:check`.
